# 💪 FitZone Club — Сайт спортивного клуба

##  Описание проекта

**FitZone Club** — это веб-приложение для онлайн-взаимодействия с фитнес-клубом. Платформа позволяет пользователям просматривать актуальное расписание групповых и персональных тренировок, записываться на занятия, отслеживать свой прогресс, добавлять тренировки в избранное и покупать абонементы онлайн.

Для тренеров и администраторов предусмотрены инструменты управления расписанием и пользователями. Проект автоматизирует ключевые процессы клуба и создаёт удобное цифровое пространство для клиентов.

## 🎯 Целевая аудитория

- Люди, ведущие активный образ жизни (от 16 лет)
- Клиенты, желающие записываться на тренировки онлайн
- Пользователи, которые хотят следить за своим прогрессом
- Тренеры и администраторы фитнес-клуба

## ⚙️ Ключевой функционал

- 📅 Просмотр расписания тренировок
- ✍️ Онлайн-запись на групповые и персональные занятия
- 👤 Личный кабинет с историей посещений и прогрессом
- 💳 Покупка абонементов онлайн
- ❤️ Добавление тренировок в избранное
- 🔐 Регистрация и авторизация пользователей (роли: user, trainer, admin)
- 🛠️ Админ-панель для управления расписанием, пользователями и абонементами

## 🚀 Локальный запуск проекта

### 1. Клонировать репозиторий

```bash
git clone https://github.com/hsgfhljf/web.fitzone.club.git
cd web.fitzone.club
```

### 2. Установить зависимости

```bash
npm install
```

### 3. Настроить базу данных (XAMPP)

- Запусти XAMPP Control Panel → **Start** для **Apache** и **MySQL**
- Открой `http://localhost/phpmyadmin`
- Создай базу данных: `fitzone_db` (кодировка `utf8mb4_general_ci`)
- Выполни SQL-запрос из файла `db/init.sql`

### 4. Настроить переменные окружения

Создай файл `.env` в корне проекта:

```env
PORT=5000
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=
DB_NAME=fitzone_db
JWT_SECRET=fitZoneSecretKey2025
```

> Если у пользователя `root` есть пароль — укажи его в `DB_PASSWORD`

### 5. Запустить сервер

```bash
node server.js
```

Сервер запустится на `http://localhost:5000`

### 6. Открыть в браузере

- Главная страница: `http://localhost:5000`
- Страница входа: `http://localhost:5000/auth/login.html`
- Страница регистрации: `http://localhost:5000/auth/register.html`

## 📡 API Эндпоинты

### Аутентификация

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | `/api/auth/register` | Регистрация пользователя |
| POST | `/api/auth/login` | Вход в систему |
| GET | `/api/auth/me` | Получить данные текущего пользователя |

### Тренировки

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/api/trainings` | Получить список всех тренировок |
| GET | `/api/trainings/:id` | Получить детали тренировки |
| POST | `/api/trainings` | Создать тренировку (только авторизованные) |
| PUT | `/api/trainings/:id` | Обновить тренировку (только авторизованные) |
| DELETE | `/api/trainings/:id` | Удалить тренировку (только авторизованные) |

### Бронирования

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | `/api/bookings` | Записаться на тренировку |
| GET | `/api/bookings` | Получить все бронирования пользователя |
| DELETE | `/api/bookings/:id` | Отменить запись |

## 🗄 Схема базы данных

### Таблица `users`

| Поле | Тип | Описание |
|------|------|----------|
| `id` | INT PRIMARY KEY AUTO_INCREMENT | Уникальный идентификатор |
| `email` | VARCHAR(255) UNIQUE | Email пользователя |
| `password_hash` | VARCHAR(255) | Хешированный пароль |
| `name` | VARCHAR(100) | Имя пользователя |
| `role` | VARCHAR(50) | Роль (user, trainer, admin) |
| `created_at` | TIMESTAMP | Дата регистрации |

### Таблица `trainings`

| Поле | Тип | Описание |
|------|------|----------|
| `id` | INT PRIMARY KEY AUTO_INCREMENT | ID тренировки |
| `title` | VARCHAR(255) | Название тренировки |
| `description` | TEXT | Описание |
| `type` | VARCHAR(50) | Тип (yoga, crossfit, aerobic, gym) |
| `trainer_id` | INT (FK) | ID тренера |
| `date_time` | DATETIME | Дата и время |
| `duration_minutes` | INT | Длительность в минутах |
| `max_seats` | INT | Максимальное количество мест |
| `available_seats` | INT | Доступное количество мест |
| `price` | DECIMAL(10,2) | Цена |
| `created_at` | TIMESTAMP | Дата создания |

### Таблица `bookings`

| Поле | Тип | Описание |
|------|------|----------|
| `id` | INT PRIMARY KEY AUTO_INCREMENT | ID записи |
| `user_id` | INT (FK) | ID пользователя |
| `training_id` | INT (FK) | ID тренировки |
| `status` | ENUM | Статус (confirmed, cancelled, completed) |
| `booked_at` | TIMESTAMP | Дата записи |
